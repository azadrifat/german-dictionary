# German dictionary (offline, ad-free)

Offline German-English dictionary for Android.

- Dictionary data: Wiktionary contributors, extracted with wiktextract and published by kaikki.org. Licence: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
- Audio recordings: Wikimedia Commons (free licences, authors credited on each file page).
- No ads, no tracking.
